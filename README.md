# TaskMaster (v1.2.5)

O TaskMaster é uma aplicação móvel simples e eficiente para gestão de tarefas diárias e listas personalizadas (como listas de compras e contas), desenvolvida com React Native (CLI).

## Tecnologias Utilizadas

- **React Native (CLI)** (Desenvolvimento nativo sem Expo)
- **React Navigation** (Navegação fluida entre ecrãs)
- **AsyncStorage** (Persistência local e armazenamento offline de dados)

## Funcionalidades

- Criação, visualização e remoção de listas de tarefas.
- Adição dinâmica de itens e gestão de estado local.
- Armazenamento totalmente offline e persistente.
- Interface limpa e responsiva.
